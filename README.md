# Desktop Alarm Clock Application ⏰

Bu proje, **C#** (veya VB.NET) ve **Windows Forms** teknolojileri kullanılarak geliştirilmiş, kullanıcı dostu bir masaüstü alarm saatidir.

## 🚀 Özellikler
* **Canlı Saat:** Dijital formatta anlık saat gösterimi.
* **Alarm Kurma:** Kullanıcının belirlediği saat ve dakikada alarm çalma.
* **Sesli Uyarı:** Alarm zamanı geldiğinde ses dosyası oynatma veya sistem uyarısı verme.
* **Erteleme/Durdurma:** Alarmı durdurma veya erteleme fonksiyonları.

## 🛠️ Kullanılan Teknolojiler
* **Dil:** C# .NET (veya Visual Basic .NET)
* **Arayüz:** Windows Forms (WinForms)
* **IDE:** Visual Studio

## 📷 Nasıl Çalışır?
1. Uygulamayı başlatın.
2. Alarm kurmak istediğiniz saati seçin.
3. "Kur" butonuna basın.
4. Belirtilen saatte uygulama sizi uyaracaktır.
